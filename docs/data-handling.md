# Fledge データ取扱一覧表

最終更新: 2026-08-30

Fledge が扱うデータを、**現時点で実装済みのもの** と **今後導入を検討しているもの** に分けて整理した一覧表です。  
説明文より先に対象を確認したいときの早見表として使ってください。

関連: [README](../README.md) / [PRIVACY.md](../PRIVACY.md) / [TERMS.md](../TERMS.md) / [spec.md](./spec.md)

## 1. 現時点で扱っているデータ

> 2026-08-30 時点。設定・アカウントは AppData（settingsRoot）、ゲームデータは configRoot（既定も AppData）。Fledge 独自アカウント、独自解析、広告 SDK は未導入です。

| 区分 | データ項目 | 例 | 取得元 | 保存場所 / 送信先 | 利用目的 | 保存期間の目安 | 備考 |
|------|------------|----|--------|-------------------|----------|----------------|------|
| 端末内設定 | ランチャー設定 | テーマ、UI サイズ、メモリ、起動ページ、Discord RPC 設定 | ユーザー入力 | `<settingsRoot>/Settings/` | アプリ設定の保持 | ユーザーが削除・初期化するまで | 端末内のみ（AppData。更新で消えない） |
| アカウント表示情報 | Microsoft / Minecraft の表示情報 | MCID、UUID、任意の XUID、アバター URL | Microsoft / Minecraft | `<settingsRoot>/Accounts/index.json` | ログイン状態の表示、アカウント切替 | ログアウトまたは削除まで | 端末内のみ |
| 認証情報 | Microsoft / Minecraft トークン | アクセストークン、リフレッシュトークン | Microsoft / Minecraft | `<settingsRoot>/Accounts/secrets/` | 再ログイン省略、ゲーム起動 | ログアウトまたは削除まで | Electron `safeStorage` で暗号化 |
| インスタンス情報 | ゲームごとの設定と付随データ | インスタンス名、バージョン、ローダー、メモリ、JVM 引数、ワールド、Mod、`options.txt`、`config/` | ユーザー入力・ゲーム生成 | `<configRoot>/Instances/` | 起動、管理、バックアップ | ユーザーが削除するまで | 端末内のみ。ゲーム内設定も含めてインスタンスごと |
| スキン情報 | 選択中／アップロード済みスキン | スキン名、モデル、画像ファイル | ユーザー入力・同梱データ | `<configRoot>/Data/Skins/` | 表示、選択、Minecraft プロフィールへの適用 | ユーザーが削除するまで | 端末内のみ |
| キャッシュ | 一時保存データ | ダウンロード済みファイル、取得済みメタデータ、導入済みマーカー、展開済みネイティブ | 外部配布元 | `<configRoot>/Data/Cache/`、`Data/Minecraft/` | 再ダウンロード削減、起動高速化 | ユーザーが削除するまで | キャッシュクリア可。ネイティブは容量と引き換えに再利用 |
| ログ | 動作記録 | 起動ログ、エラー情報 | アプリ実行時 | `<configRoot>/Data/Logs/` | 不具合確認 | ユーザーが削除するまで | 現時点で外部送信なし |
| Java ランタイム | Fledge 管理下の Java | Temurin 8 / 17 / 21 / 25 | Eclipse Adoptium | `<configRoot>/Data/java-version/` | ゲーム起動 | ユーザーが削除するまで | 端末内に展開 |
| ニュース | お知らせ表示用データ | タイトル、本文、公開日、任意 URL | GitHub 正本 + 端末キャッシュ + 同梱データ | `<configRoot>/Data/News/` / [news/news.ja.json](../news/news.ja.json) | UI 表示 | キャッシュ約 1 時間、オフライン時は前回取得分 | GitHub から取得。初回オフラインは同梱 JSON |
| 外部通信 | コンテンツ検索情報 | 検索語、対象バージョン、ローダー | ユーザー操作 | Modrinth API | コンテンツ検索・導入 | 外部サービス側の定めによる | Fledge 独自保存前提なし |
| 外部通信 | アバター表示用識別子 | Minecraft UUID | 既存アカウント情報 | mc-heads.net | 顔アイコン表示 | 外部サービス側の定めによる | Microsoft 側 URL があれば優先 |
| 外部通信 | Discord 表示情報 | 状態、インスタンス名、バージョン、ローダー | アプリ実行時 | ローカル Discord アプリ | Rich Presence 表示 | Discord 側の扱いによる | 既定オフ |

## 2. 将来導入を検討しているデータ

> web 連携や着せ替え機能の実装時に再確認・更新する前提の案です。未確定項目を含みます。

| 区分 | 想定データ項目 | 想定される利用目的 | 想定保存先 / 送信先 | 想定保存期間 | 収集方針 |
|------|----------------|--------------------|---------------------|--------------|----------|
| 独自アカウント | Fledge アカウント識別子 | web 連携、着せ替え設定の紐付け | Fledge 運用基盤 | 未定（公開時に明記） | 必要最小限 |
| 会員プロフィール | 表示名、連携状態、設定識別子 | UI 表示、設定同期 | Fledge 運用基盤 | 未定 | 必要最小限 |
| 着せ替え設定 | 選択中テーマ、所有アイテム、適用状態 | 着せ替え機能提供 | Fledge 運用基盤 | 未定 | 機能提供に必要な範囲 |
| 利用率解析 | 機能ごとの利用有無、継続利用状況 | サービス改善、優先度判断 | Fledge 運用基盤 | 未定 | 集計中心、必要最小限 |
| 障害対応用データ | 失敗種別、発生回数、最小限の技術情報 | 障害調査、安定化 | Fledge 運用基盤 | 未定 | 必要最小限 |

### 将来も収集対象にしない前提のもの

| 項目 | 方針 |
|------|------|
| パスワードの平文 | 収集しない |
| 認証トークンの公開ソースへの混入 | 許容しない |
| 個人を直接特定するために不要な情報 | 原則収集しない |
| 公開リポジトリに載せるべきでない秘密情報 | 含めない |

## 3. 公開前に確定させる項目

将来の独自アカウントや解析を実装する前に、少なくとも次を確定し、`PRIVACY.md` と `TERMS.md` に反映します。

1. 取得する情報の一覧
2. 各情報の利用目的
3. 保存期間
4. 第三者提供の有無
5. 削除依頼や退会時の扱い
6. ログや解析データの匿名化 / 集計方針
7. ソースコード・公開リポジトリへ含めない秘密情報の運用ルール

---

## 4. 運用ルール

- 個人情報は必要最小限にとどめる
- パスワード、認証トークン、個人情報、秘密鍵などをソースコードや公開リポジトリへ含めない
- 文書と実装に差が出た場合は、GitHub 上の文書を先に更新する
- 大きな変更の前後で `README.md`、`PRIVACY.md`、`TERMS.md`、本一覧表を見直す
