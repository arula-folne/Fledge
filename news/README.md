# お知らせ（News）

Fledge アプリのホーム画面に表示するお知らせデータです。

## ファイル

| ファイル | 説明 |
|----------|------|
| `news.ja.json` | 日本語のお知らせ一覧（アプリが取得する正本） |

## JSON 形式

各要素は次のフィールドを持ちます。

| フィールド | 必須 | 説明 |
|------------|------|------|
| `id` | はい | 一意 ID（英数字とハイフン） |
| `title` | はい | タイトル |
| `body` | はい | 本文（改行は `\n`） |
| `publishedAt` | はい | 公開日時（ISO 8601） |
| `url` | いいえ | 詳細リンク（Issues や PRIVACY.md など） |

## アプリ側の取得

1. 起動時などに GitHub 上の `news/news.ja.json` を取得
2. 成功したら `Data/News/news.ja.json` にキャッシュ（約 1 時間有効）
3. 取得できない場合はキャッシュ → アプリ同梱 JSON → 最小フォールバックの順で表示

取得 URL は `@fledge/shared` の `NEWS.remoteUrl` を参照してください。

## 更新手順

1. この `news.ja.json` を編集して `main` に push
2. ユーザーのアプリは次回の取得タイミング（最大約 1 時間）で反映
3. 同梱フォールバックも合わせて更新する場合は `apps/desktop/resources/news.ja.json` も同期する
